# AI Architect Handbook

A comprehensive, production-focused handbook for Software Engineers, Technical Leads, Solution Architects, and AI Engineers who want to design, build, deploy, and operate modern AI systems.

## Vision

This repository aims to become a complete AI Architect handbook covering everything from Large Language Models (LLMs) and Retrieval-Augmented Generation (RAG) to AI Agents, Model Context Protocol (MCP), production deployment, observability, security, and enterprise architecture.

The focus is on understanding not only *how* AI systems work, but *why* architectural decisions matter in production.

## Repository Structure

Each chapter is self-contained so that documentation, Java examples, Python examples, diagrams, and exercises can evolve together:

```text

```
